User guide

Configuration

Use YAML, TOML, or JSON with the same option names.

Choose one file.

Set PIXIE_CONFIG to its path. Otherwise Pixie searches the default filenames.

YAML · config-pixie.yml

addr: 0.0.0.0:8080
workers: 4

TOML · config-pixie.toml

addr = "0.0.0.0:8080"
workers = 4

JSON · config-pixie.json

{
  "addr": "0.0.0.0:8080",
  "workers": 4
}

PIXIE_CONFIG=./config-pixie.toml PIXIE_WEB_ROOT=./my-site cargo run --locked

Set PIXIE_CONFIG to the file you saved. Its extension selects the parser: .yml, .yaml, .toml, or .json. Relative paths use the process working directory. Use absolute paths in services.

Configuration reference

Setting Default Meaning
addr 127.0.0.1:80 Full listen address. Takes priority over host and port.
host 127.0.0.1 Used with port when addr is absent.
port 80 TCP listen port.
workers 4 Connection worker count. Zero falls back to 4.
tls.cert_file Absent Required PEM certificate chain when tls is present.
tls.key_file Absent Required unencrypted PEM private key.
tls.client_ca_file Absent Trusted client CAs; setting it requires client certificates.
http3.addr Absent Optional QUIC/UDP listen address. Requires TLS; HTTP/3 support is experimental.

address is an alias for addr; nb_worker is an alias for workers. Port 80 may require elevated privileges; prefer 8080 for local use. The shipped sample configuration uses 8080.

To enable experimental HTTP/3, configure TLS and add http3: { addr: "0.0.0.0:8443" }. Expose that port over UDP in the host firewall and deployment. See the TLS guide.

Which file is loaded?

  1. If PIXIE_CONFIG is nonempty, Pixie uses that path.
  2. Otherwise, it looks for config-pixie.yml, config-pixie.yaml, config-pixie.toml, then config-pixie.json in the working directory.
  3. Then it checks the same names under /etc/pixie/.
  4. Without a file, compiled defaults apply.
A missing explicit file uses the built-in defaults.

If the file is missing, Pixie uses built-in defaults and skips other locations. Invalid contents or an unsupported extension stop startup. Check the startup log for the listen address.

Web root lookup

  1. An existing directory selected by PIXIE_WEB_ROOT.
  2. web/ at the source manifest path, if present.
  3. /usr/share/pixie/web.

An invalid PIXIE_WEB_ROOT logs a warning and uses the fallback. Restart Pixie after config or TLS changes. Page files reload on each request.
