Preview locally

This site uses plain HTML, CSS, and a small JavaScript file. There is no package manager, build command, or remote font dependency. From the repository root, use an installed static server, for example Python:

python3 -m http.server 8000 --directory docs

Open http://localhost:8000/. You can also open docs/index.html directly; navigation and reading work without JavaScript.

Serve this documentation with a general static host.

Pixie's current router serves named HTML pages only, so it cannot serve this site's separate stylesheet and script. Use GitHub Pages, NGINX, or another static file host for this documentation.

The simplest repository setup: GitHub Pages

The release workflow already publishes the signed APT repository to GitHub Pages. It now copies docs/ into the same artifact at public/docs/, preserving the APT files at the root.

  1. In GitHub repository Settings → Pages, select GitHub Actions as the source.
  2. Configure the APT signing secrets required by .github/workflows/publish-apt.yml.
  3. Publish a version tag matching Cargo.toml when you intend to release.
  4. Open https://laflut3.github.io/Pixie/docs/ after the workflow succeeds.

Documentation deploys with that release workflow. The URL is the expected destination, not a claim that it is already live. Avoid a second Pages workflow that uploads only docs: it would replace the APT repository.

Any static host

Upload the contents of docs/ into a directory on your host. All local links are relative, so the site works at the domain root or under /docs/. HTTPS and cache policy belong to the host.
