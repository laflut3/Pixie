Host the docs

Static HTML. No build required.

Preview locally

From the repository root:

python3 -m http.server 8000 --directory docs

Open localhost:8000.

Pixie serves CSS and JavaScript assets, so this documentation can also run on Pixie.

Cloudflare Pages

  1. Connect the laflut3/Pixie repository and select main.
  2. Set build command to exit 0 and output directory to docs.
  3. Add pixie.fleothing.com under Custom domains.

Each push to main deploys the site. See Cloudflare's Pages guide and custom domain guide.

Any static host

Serve docs/ at the domain root or under /docs/.
