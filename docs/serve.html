User guide

Serve a website

Drop a site into Pixie’s site directory and serve it.

Add a site

sudo mkdir -p /etc/pixie/sites/default
sudo cp -R ./dist/. /etc/pixie/sites/default/
curl -i http://localhost:8080/

Pixie serves index.html for /, supports nested paths and common asset MIME types, and returns 404.html for missing files.

Mount a site into Docker

docker run --rm -p 8080:8080 \
  -v "$PWD/dist:/etc/pixie/sites/default:ro" \
  ghcr.io/laflut3/pixie:latest

React routes

For a single-page app, enable the index fallback for extensionless routes:

docker run --rm -p 8080:8080 \
  -v "$PWD/dist:/etc/pixie/sites/default:ro" \
  -e PIXIE_SPA_FALLBACK=true \
  ghcr.io/laflut3/pixie:latest

Multiple sites

Use hostname-based site folders to serve several sites from one Pixie process.
