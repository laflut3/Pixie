How it works

Runtime and TLS

Configuration, connections, and logs.

Configuration

src/config.rs reads YAML, TOML, or JSON by extension. Missing options use defaults. TLS requires a certificate and key. See configuration.

TLS and mTLS

src/tls.rs loads the PEM certificate and key. Add a client CA to require mTLS. ALPN negotiates HTTP/2 or HTTP/1.1. Experimental HTTP/3 uses TLS over a separate QUIC listener.

Workers

src/server.rs runs async connections on a Tokio thread pool. Pixie has no connection limit.

Logging

src/logger.rs writes startup, warning, and error messages to stderr. There are no access logs or metrics endpoint.
