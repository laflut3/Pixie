Run Pixie

Start the published container with its default settings:

docker run --rm -p 8080:8080 ghcr.io/laflut3/pixie:latest

Open http://localhost:8080/. To show your own pages, follow Serve a website. For local development or custom settings, start with deployment and configuration.

Read the version you run.

These pages describe this source branch. A published image or package may contain an earlier release. HTTP/3 is experimental and opt-in. HTTP/1.2 and HTTP/1.3 are not standardized versions.
