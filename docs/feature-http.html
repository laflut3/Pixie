HTTP request handling.

HTTP versions, validation, and response behavior.

Feature: HTTP/1.x and HTTP/2

src/server.rs uses Tokio and Hyper to serve HTTP/1.0, HTTP/1.1, and HTTP/2. HTTP/2 is negotiated through TLS ALPN; plaintext HTTP uses HTTP/1.x. HTTP/1.1 requests require Host. Pixie accepts GET and HEAD and closes HTTP/1 connections after one response.

Result Status
Page found 200
Page missing or rejected route 404
Invalid request or unsupported body 400
Unsupported method 405
Headers exceed the limit 431
File read failure 500
Unsupported HTTP version 505

HTTP/3 over QUIC is not implemented. Caching validators, ranges, compression, and uploads are also outside the current feature set. HTTP/1.2 and HTTP/1.3 are not standardized versions.
