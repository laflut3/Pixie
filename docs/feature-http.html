HTTP handling

Supported versions and response codes.

HTTP/1.x and HTTP/2

src/server.rs serves HTTP/1.0, HTTP/1.1, and HTTP/2. HTTP/2 uses TLS ALPN. Plaintext connections use HTTP/1.x. HTTP/1.1 requires Host. Pixie accepts GET and HEAD, then closes HTTP/1 connections.

Result Status
Page found 200
Page missing or rejected route 404
Invalid request or unsupported body 400
Unsupported method 405
Headers exceed the limit 431
File read failure 500
Unsupported HTTP version 505

HTTP/3 over QUIC is experimental and opt-in. Pixie does not support caching validators, ranges, compression, or uploads. HTTP/1.2 and HTTP/1.3 are not standardized versions.
