User guide

Deploy Pixie

Use Docker, Cargo, a Linux package, or Helm.

Docker image

Pull the latest image or pin a release:

docker pull ghcr.io/laflut3/pixie:latest
docker pull ghcr.io/laflut3/pixie:v1.2.0

View image versions · Release notes and packages

Run the latest image. It supports amd64 and arm64.

docker run --rm -p 8080:8080 ghcr.io/laflut3/pixie:latest

Build from the repository or use Compose:

docker build -f infrastructure/docker/Dockerfile -t pixie:local .
docker run --rm -p 8080:8080 pixie:local

# Or use the published image through Compose
docker compose -f infrastructure/docker/compose.yaml up -d

Compose mounts infrastructure/config/config-pixie.yml. Stop it with docker compose -f infrastructure/docker/compose.yaml down.

Local Cargo build

Run from the repository root with the Rust version in Cargo.toml.

PIXIE_CONFIG=infrastructure/config/config-pixie.yml cargo run --locked

The sample listens on 0.0.0.0:8080 and serves web/.

Debian / Ubuntu and Arch Linux

Review the installer before running it. APT packages support amd64 and arm64:

curl -fsSLo install-pixie.sh https://raw.githubusercontent.com/laflut3/Pixie/main/infrastructure/apt/install.sh
less install-pixie.sh
bash install-pixie.sh
sudo systemctl enable --now pixie

Arch Linux (x86_64 or aarch64):

yay -S pixie-git
sudo systemctl enable --now pixie

Build a Debian package locally:

infrastructure/scripts/build-deb.sh
sudo apt install ./pixie_*.deb
sudo systemctl enable --now pixie

Config: /etc/pixie/config-pixie.yml. Logs: journalctl -u pixie -f.

Kubernetes with Helm

helm upgrade --install pixie infrastructure/helm/pixie \
  --namespace pixie --create-namespace
kubectl -n pixie port-forward service/pixie-pixie 8080:8080

The chart creates a ClusterIP service. Add an Ingress or Gateway for external traffic. Set tls.enabled=true and tls.secretName to mount a TLS Secret. HTTP/3 also needs http3.enabled=true and an exposed UDP port.

Check your endpoint

curl -i http://localhost:8080/
curl -I http://localhost:8080/
curl -i http://localhost:8080/missing

Expect 200 for the home page and 404 for a missing page. See configuration or TLS and mTLS to change settings.
