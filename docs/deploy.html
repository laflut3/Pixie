Deploy Pixie

Install from a published image, chart, or Linux package.

Docker image

Pull the latest or pin a SemVer release:

docker pull ghcr.io/laflut3/pixie:latest
docker pull ghcr.io/laflut3/pixie:v1.2.0

View image versions · Release notes and packages

Run the latest image. It supports amd64 and arm64.

docker run --rm -p 8080:8080 ghcr.io/laflut3/pixie:latest

The port mapping exposes Pixie's port 8080 at localhost:8080.

Debian / Ubuntu

curl -fsSL https://raw.githubusercontent.com/laflut3/Pixie/main/infrastructure/apt/install.sh | bash -s -- --setup-only
sudo apt install pixie
sudo systemctl enable --now pixie

Arch Linux

curl -fsSL https://raw.githubusercontent.com/laflut3/Pixie/main/infrastructure/arch/install.sh | bash
sudo pacman -Syu pixie
sudo systemctl enable --now pixie

Linux installer

curl -fsSL https://raw.githubusercontent.com/laflut3/Pixie/main/infrastructure/scripts/install.sh | bash
sudo systemctl enable --now pixie

Kubernetes with Helm

helm repo add pixie https://laflut3.github.io/Pixie/charts
helm repo update
helm upgrade --install pixie pixie/pixie \
  --namespace pixie --create-namespace
kubectl -n pixie port-forward service/pixie-pixie 8080:8080

Config and site files are described in Configuration and Multiple sites. See TLS and mTLS for HTTPS.
