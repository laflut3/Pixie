Routing and files

Page names map to HTML files in the web root.

Static routes

src/router.rs appends .html to valid page names. The home page is hello.html. Query strings are ignored. Paths with separators, encoded characters, or dot segments are rejected. Pixie reads each file as UTF-8 on request.
